Source and build relationships
      
Paths below are relative to each workbench directory under apps/.
    
        
  • Decision model · src/model.js
    The browser interface and analyst CLI import the calculation rules. The standalone builder embeds the model.
    • 
        
  • Browser interface · src/app.js
    The interface applies the model to the scenario a reviewer is editing. The builder includes this interface in the portable page.
    • 
        
  • Standalone builder · scripts/build-standalone.mjs
    The build script combines the HTML template, styles, model and interface into one file.
    • 
        
  • Portable workbench · standalone.html
    The finished browser workbench opens from disk or the local launcher. Use its JSON export to move a scenario.
    • 
        
  • Analyst CLI · scripts/analyze.mjs
    The command line runs the same model against explicit local inputs. Its commands and output formats are documented in each workbench README.
    •
