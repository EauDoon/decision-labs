What's new

These tools ship inside the four local workbenches. They run in your browser on the case you opened. They do not call a live partnership, merchant, vote, or bank.

  • Share-to-hold in Partnership Breakpoint

    Solve the minimum revenue share at which a named participant still meets their floor in the open case, then apply it if you choose. The solver is local arithmetic. It does not quote a market or predict who will stay.

  • Residual coverage in Common Cart

    After a winning offer is chosen, leftover whole-buyer demand can be tested against the next-best other offer. Merchant export stays aggregate. This is a planning view, not checkout, inventory, or a second live order.

  • Veto groups in The Smallest Agreement

    Mark a group whose average support must meet the approval threshold, or the higher of that threshold and the group's support floor. A veto here is a number you entered, not a legal right.

  • Gate Gantt in Weekend Gap

    Scrub 72 hours of issuer, bank, payout, and FX windows on the synthetic calendar, with a table fallback. The drawing does not connect to a bank or a live redemption queue.

How it works

This page is a catalog. Each Open workbench link loads one generated file from this repository. You can also open that file from disk. Node.js is only required if you want the loopback launcher or to run tests.

Standalone files

Every workbench ships standalone.html: interface, styles, and model in one document. Opening it from this launcher or by double-clicking the file does not require a network connection. The file makes no requests to Decision Labs or to anyone else.

JSON export

Valid drafts can autosave in this browser. That storage is not a backup and it does not move with you. Use Export JSON to keep a portable copy, to hand a case to someone else, or to reopen the work after clearing site data. A file:// address is a path on your device, not a shareable link, so standalone mode directs sharing through that export.

Independent workbenches

The four tools do not share drafts, storage keys, or versions. A partnership case cannot open in Common Cart. Closing this catalog does not close a workbench you already opened. Treat each app as its own product that happens to live in the same repository.

Trust and limits

This catalog and the four workbenches are local-first decision aids. They help you inspect a bounded case. They do not make the decision, execute a transaction, or speak for a counterparty.

  • Local-first. Pages run in your browser. The optional launcher binds loopback only. Nothing here calls a remote API or loads live market, merchant, or account data.
  • No account. There is no sign-in, cloud save, or hosted workspace. Browser storage stays on this device. Clear the site data and those drafts are gone unless you exported JSON.
  • Deterministic math. The same valid inputs produce the same outputs. The models do not sample, forecast, or assign probabilities, prices, fairness, or legitimacy.
  • Not a decision maker. A ranked shock, a pooled offer, a clause package, or a weekend queue is evidence for a conversation. People keep judgment, governing rules, and accountability.
  • Model notes live in each workbench. Formulas, units, and non-goals are documented beside the tool that uses them. This launcher does not serve those files; open the workbench when you need the exact conventions.

This page is the catalog. It is not a combined product version. Partnership Breakpoint, Common Cart, The Smallest Agreement, and Weekend Gap each ship their own version and changelog.
